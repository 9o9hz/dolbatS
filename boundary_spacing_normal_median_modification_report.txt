차선 경계 간격 판정 개선 보고서
작성 기준: 2026-08-05 현재 로컬 drive_pkg

1. 수정 목적

기존 drive_pkg는 두 차선 경계가 실제 차선 폭에 해당하는지를 판단할 때
각 그룹의 단일 x_ref 좌표 차이만 사용했다.

    spacing_px = right["x_ref"] - left["x_ref"]

x_ref는 보통 BEV 높이의 88% 지점을 기준으로 계산되지만, 검출된 선이 해당
지점까지 이어지지 않으면 각 선의 y_min/y_max 범위로 독립적으로 제한된다.
그 결과 곡선이나 검출 길이가 다른 두 선에서는 서로 다른 Y 위치의 X 좌표를
비교할 수 있었다. 정상적인 DASHED-SOLID 쌍도 0.80~0.90m 간격 조건을 벗어난
것으로 판정되어 한쪽 경계가 제거될 가능성이 있었다.

이번 수정은 단일 x_ref 수평 차이를 차선 폭으로 사용하는 방식을 제거하고,
두 경계가 실제로 함께 관측되는 공통 Y 구간에서 미터 단위 법선 거리를 반복
측정한 후 그 중앙값으로 경계 쌍의 유효성을 판정하도록 변경한 것이다.


2. 기존 방식과 변경 방식 비교

[기존 방식]

1) 각 차선 그룹의 x_ref 한 점을 가져온다.
2) 두 x_ref의 수평 픽셀 차이를 계산한다.
3) pixels_per_meter_x를 기준으로 만든 허용 픽셀 범위와 비교한다.
4) 범위를 벗어나면 YOLO 신뢰도가 높은 경계 하나만 사용한다.

문제점:

- 두 경계의 x_ref가 서로 다른 Y 위치에서 계산될 수 있다.
- 곡선 또는 기울어진 차선의 수평 거리는 실제 수직 차선 폭보다 커질 수 있다.
- 한 지점의 마스크 흔들림이나 곡선 피팅 오차가 전체 판정을 결정한다.
- 정상 SOLID가 탈락하면서 fused_boundaries 대신 단일 경계 법선 이동 경로가
  생성될 수 있다.

[변경 방식]

1) 두 경계와 경로 생성 영역이 모두 겹치는 공통 Y 구간을 계산한다.
2) 공통 구간을 10px 간격으로 표본화한다.
3) 각 Y에서 왼쪽과 오른쪽 다항 곡선의 X 좌표를 동시에 계산한다.
4) 양쪽 곡선의 평균 기울기로 국소 접선과 법선 방향을 계산한다.
5) pixels_per_meter_x/y를 사용해 미터 단위 법선 간격을 계산한다.
6) 모든 유효 표본의 중앙값을 대표 차선 폭으로 사용한다.
7) 표본 산포는 MAD(Median Absolute Deviation)로 검사한다.
8) 중앙값과 MAD가 모두 유효할 때만 양쪽 경계를 함께 사용한다.


3. 새 간격 측정 결과

새 측정 함수는 다음 정보를 계산한다.

- median_m: 공통 Y 구간에서 측정한 법선 차선 폭의 중앙값
- sample_count: 정상적으로 계산된 간격 표본 수
- mad_m: 각 표본이 중앙값에서 벗어난 거리의 중앙값

중앙값은 일부 마스크 돌출이나 국소 피팅 오차에 강하다. MAD는 중앙값만
정상이고 구간별 폭이 크게 변하는 잘못된 경계 쌍을 걸러내는 역할을 한다.


4. 적용된 판정 조건

현재 설정값은 다음과 같다.

    lane_width_m: 0.85
    min_boundary_spacing_m: 0.80
    max_boundary_spacing_m: 0.90
    boundary_spacing_sample_step_px: 10.0
    boundary_spacing_min_samples: 5
    boundary_spacing_max_mad_m: 0.05

양쪽 경계를 함께 사용하려면 다음 조건을 모두 만족해야 한다.

- 유효 표본이 5개 이상이어야 한다.
- 간격 중앙값이 0.80~0.90m 범위여야 한다.
- 간격 MAD가 0.05m 이하여야 한다.
- 공통 구간에서 두 곡선이 정상적인 좌우 순서를 유지해야 한다.

조건이 하나라도 충족되지 않으면 기존과 동일하게 YOLO 신뢰도, 그룹 길이,
면적을 기준으로 신뢰도가 높은 경계 하나만 유지한다. 따라서 새 측정이
불가능한 상황에서도 기존 fail-safe 동작은 유지된다.


5. 함수별 수정 내용

[lane_processing.py]

- BoundarySpacingMeasurement 데이터 구조 추가
- LaneConfig에 표본 간격, 최소 표본 수, 최대 MAD 설정 추가
- 새 _measure_boundary_spacing() 함수 추가
- 새 _boundary_spacing_is_valid() 판정 함수 추가
- _filter_boundary_spacing()의 단일 x_ref 간격 검사를 새 측정 방식으로 교체
- _solid_dashed_solid_topology()의 DASHED-SOLID 후보 검사를 새 방식으로 교체
- 후보가 여러 개면 측정 폭이 기준 0.85m에 가까운 쌍을 우선 선택

x_ref는 완전히 삭제하지 않았다. 그룹 정렬, 좌우 후보 구분, 동일 점수 후보의
결정적 tie-break 용도로만 유지하며 차선 폭 계산에는 사용하지 않는다.

[drive_main.py]

- 새 간격 측정 파라미터 3개의 ROS 기본값 선언
- ROS 파라미터 값을 LaneConfig로 전달

[config/drive_pipeline.yaml]

- boundary_spacing_sample_step_px: 10.0 추가
- boundary_spacing_min_samples: 5 추가
- boundary_spacing_max_mad_m: 0.05 추가

[test/test_boundary_spacing.py]

- 경사진 평행 차선의 법선 폭 판정 테스트 추가
- 서로 다른 검출 길이에서 공통 Y만 사용하는 테스트 추가
- 공통 표본 부족 시 신뢰도 fallback 테스트 추가
- 간격 중앙값은 정상이지만 MAD가 큰 경계 쌍의 거부 테스트 추가


6. 적용 후 기대 효과

6.1 곡선에서 정상 SOLID 보존

곡선의 수평 간격이 0.90m를 초과하더라도 실제 법선 폭이 0.80~0.90m라면
정상적인 차선 쌍으로 인정할 수 있다. 기존 invalid_spacing_yolo_confidence
분기로 인해 정상 SOLID가 제거되는 현상이 줄어들 것으로 예상한다.

6.2 양쪽 경계 융합 경로 증가

정상 DASHED-SOLID 쌍이 유지되면 다음 상태가 증가할 수 있다.

    selection: lane2_dashed_solid_hold
    path: fused_boundaries

한쪽 경계만 0.425m 법선 이동한 경로보다 양쪽 경계에서 계산한 중심선을
융합할 수 있어 한쪽 마스크 오차에 대한 의존도가 줄어든다.

6.3 경로 소스 전환 진동 감소

기존에는 한 지점의 간격 변화로 다음 상태가 프레임마다 전환될 수 있었다.

    fused_boundaries
    -> left_boundary_normal_offset
    -> fused_boundaries

다중 표본 중앙값을 사용하면 국소 오차 하나가 전체 경계 선택을 바꾸는 빈도가
줄어들어 경로와 조향 명령의 불필요한 흔들림 감소를 기대할 수 있다.

6.4 차선 안쪽 편향 감소 가능성

정상적인 양쪽 경계를 더 오래 유지하면 한쪽 경계와 고정 반 차선 폭에만
의존하는 시간이 줄어든다. 따라서 단일 경계 오차 때문에 차량이 차선 한쪽에
붙는 편향을 완화할 가능성이 있다.

6.5 계산량 증가가 작음

후보 경계 쌍마다 일반적으로 수십 개의 Y 표본에 대해 다항식과 벡터 연산만
수행한다. YOLO 추론 비용에 비해 추가 계산량은 매우 작다.


7. 안전성과 유지된 동작

다음 항목은 변경하지 않았다.

- drive_pipeline.launch.py와 실행 명령
- drive_main/pure_pursuit 노드 구성
- 카메라 입력 및 /lane/path, /lane/path/status, /which/lane 토픽
- YOLO 검출과 그룹 생성 방식
- Pure Pursuit 및 조향 명령 생성 방식
- 유효하지 않은 경계 쌍에서 신뢰도 높은 단일 경계를 선택하는 fallback
- 기존 lane_width_m 및 0.80~0.90m 허용 범위

따라서 실행 구조와 토픽 구조에 영향을 주지 않고 경계 쌍 기하 판정만
개선되었다.

9. 한계와 추가 확인 사항

이 수정은 다음 문제를 해결한다.

- 서로 다른 Y 위치의 x_ref를 비교하는 문제
- 곡선에서 수평 거리를 실제 차선 폭으로 사용하는 문제
- 단일 표본 노이즈가 전체 경계 선택을 결정하는 문제

하지만 다음 문제를 자동으로 보정하지는 않는다.

- bev_params_0803.npz의 원근 변환 자체가 잘못된 경우
- pixels_per_meter_x/y가 실측 축척과 다른 경우
- 실제 트랙 차선 폭이 설정한 0.85m와 다른 경우
- YOLO가 물리적으로 다른 선을 높은 신뢰도로 오검출한 경우

모든 공통 Y 표본에서 차선 폭이 체계적으로 0.92~0.94m처럼 측정된다면 간격
판정 범위를 무작정 넓히기 전에 BEV 축척과 pixels_per_meter_x/y를 실측으로
재검증해야 한다.


10. 최종 요약

기존:

    한 점 x_ref 수평 픽셀 간격
    -> 범위 검사
    -> 오류 시 한 경계 제거

변경:

    공통 Y 다중 표본
    -> 미터 단위 법선 거리
    -> 중앙값 및 MAD 검사
    -> 정상 쌍은 양쪽 경계 융합
    -> 측정 불가/불안정 시 기존 신뢰도 fallback

이번 변경으로 곡선에서 정상 경계 쌍을 유지할 기하학적 타당성과 국소 노이즈에
대한 강건성이 높아졌으며, 실행 구조와 토픽 호환성은 그대로 유지된다.
